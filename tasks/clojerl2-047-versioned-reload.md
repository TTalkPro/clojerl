# clojerl2-047 版本化热替换与回收

状态:已完成(2026-10-13)
里程碑:M7
依赖:clojerl2-044

## 目标

BEAM 每个模块只有两个版本:还有进程停在旧版本时,再次加载会失败。规则频繁修改、调用可能持续很久时需要不受此限。

## 工作内容

- [x] `clj2:load(Src, #{versioned => true})`:每次编译成独立模块 `<ns>$v<N>`,命名空间注册表指向最新版本;
  `clj2:call/3` 与 `clj2:module/1` 走当前版本,正在执行的调用在自己的版本上跑完
- [x] `clj2:gc/0,1`:删除并清除没有进程在用的旧版本,仍在用的保留到下次;`unload/1` 删除所有版本

## 结论

实测:一个进程停在 v1 时,普通模式第三次加载报 `old_code_in_use`,版本化模式连续加载 v2–v4 均成功,进程退出后 gc 回收 v1。
